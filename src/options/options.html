使用说明

  1. 选择 AI 提供商（OpenAI、Gemini 或 GLM）
  2. 输入你的 API Key（必填）
  3. 可选择自定义 API Endpoint
  4. 选择要使用的模型
  5. 调整高级参数（可选）
  6. 点击"保存配置"完成设置

使用方法：在任意网页上选中文字，点击出现的"AI解释"按钮即可获取解释。
